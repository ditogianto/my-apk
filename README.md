## ⚡ Fitur Rilis Baru (v1.0.1)
- **Native Android Hardware Back Button:**
  - Penanganan tombol kembali hardware/gestur Android secara cerdas (*hierarchical LIFO stack*).
  - Menutup modal aktif (Image Viewer, Challenge Modal, Settings, Mobile Drawer) sebelum navigasi.
  - Kembali ke Beranda (*Home Dashboard*) jika sedang membaca materi/modul.
  - Proteksi *double-tap to exit* dengan notifikasi toast konfirmasi saat berada di halaman utama.
- **In-App OTA Auto-Updater:**
  - Pengecekan versi pembaruan langsung dari repositori GitHub tanpa kabel data atau transfer manual dari PC.
  - Unduhan satu klik langsung ke penyimpanan handphone.
